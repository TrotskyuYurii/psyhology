# Простір — сайт психологічного тестування

Версія 0.2. Монорепозиторій: React 19.3.1 + TypeScript + Vite, NestJS + TypeScript, MongoDB + Mongoose.

## Структура

- `apps/web` — React-інтерфейс: каталог, пошук, фільтри, плеєр, локальна історія та експорт JSON.
- `apps/api` — NestJS API: каталог, перевірка відповідей, серверний підрахунок і підключення MongoDB.
- `packages/contracts` — спільні типи запитів і результатів.
- `deploy` — Dockerfile та Nginx.
- `compose.yaml` — frontend, backend, MongoDB з окремим томом даних.
- `.github/workflows/ci.yml` — перевірки та збірка при push/PR у main.

## Локальний запуск

Потрібен Node.js 22.12 або новіший; рекомендовано Node.js 24.

```sh
npm ci
npm run dev
```

Frontend: http://localhost:4173. API: http://127.0.0.1:3001/api.
Vite передає запити /api до backend. Без .env API запускається у демонстраційному режимі з каталогом у пам’яті.

Для MongoDB скопіюйте `.env.example` у `.env` і задайте MONGODB_URI. MongoDB має вже працювати. API під’єднається до бази та додасть три демонстраційні опитування лише за їх відсутності; наявні документи не перезаписуються. При недоступній налаштованій базі застосунок не підміняє її демонстраційними даними.

Попередній ключ localStorage `prostir-v1` збережено: історія та чернетки з попереднього прототипу доступні на тому самому origin. localhost та 127.0.0.1 є різними origin.

## Перевірки

```sh
npm run typecheck
npm test
npm run build
```

Збірка web: apps/web/dist. Збірка API: apps/api/dist. Папки збірки не зберігаються в Git.

## API

- GET /api/health — стан API і підключення бази.
- GET /api/tests — публічний каталог без ключів зворотного обрахунку.
- POST /api/tests/:id/score — тіло `{"version":1,"answers":[3,3,3,3,3,3]}`.

Некоректні відповіді та версії повертають 400, невідомий тест — 404.
Backend перевіряє повноту відповідей та застосовує прямі й зворотні ключі. Відповіді передаються на сервер для підрахунку, але не записуються в базу; історія поки локальна.

## Розгортання в aaPanel

Потрібен Docker із Compose:

```sh
docker compose up -d --build
```

В aaPanel налаштуйте HTTPS-сайт із reverse proxy на http://127.0.0.1:8080. Nginx у контейнері обслуговує React і проксіює /api до NestJS. Backend і MongoDB не публікують порти на хост. У production MONGODB_URI обов’язкова.

Конфігурація є основою розгортання прототипу. Перед зберіганням персональних даних потрібні автентифікація MongoDB, резервні копії, політика доступу та авторизація користувачів. Не використовуйте `docker compose down -v`, якщо потрібно зберегти базу.

CI вже описано; автоматична доставка на ваш сервер поки не налаштована, оскільки потрібні його реквізити та спосіб доступу. Push сам по собі не запускає production-деплой.

## Межі прототипу

Демонстраційні питання не є валідованими методиками. Авторизацію, персональні результати в MongoDB, пакети, CMS, платежі та PDF-звіти додаватимемо окремо. Docker/MongoDB інтеграція потребує перевірки на машині з установленим Docker; локально перевірено демонстраційний режим API.
