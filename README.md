# Простір — сайт психологічного тестування

Версія 0.1: адаптивний прототип українською без залежностей.

Реалізовано каталог із пошуком і тематичними фільтрами, три демонстраційні опитування, покрокове проходження, клавіші 1–5, локальні чернетки, прямий і зворотний підрахунок, історію, видалення даних та експорт JSON. Демонстраційні питання не є валідованими методиками.

Запуск: `python -m http.server 4173 --directory dist`.

## Подальша розробка

1. Узгодити назву, дизайн і ліцензований стартовий набір методик та їхні ключі.
2. Додати сервер, автентифікацію, базу даних, версіонування тестів і політику роботи з персональними даними.
3. Реалізувати пакети, перевірені формули агрегації та графіки динаміки.
4. Додати CMS, платежі через вебхуки, PDF-звіти та статті.

Рекомендований у наданому ТЗ стек Next.js / MongoDB потребує окремої серверної реалізації та сумісного хостингу. Цей прототип є основою для узгодження поведінки інтерфейсу, а не завершеною платформою.
